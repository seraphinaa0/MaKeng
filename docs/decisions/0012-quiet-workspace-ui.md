# 0012 — Quiet IELTS workspace

Date: 2026-10-05

## Decision

Use the user's visual reference as a direction: an inset, rounded lavender
workspace, violet actions, compact icon navigation, a mountain silhouette on
Home, and low-noise practice surfaces. Preserve the MaKeng identity and both
light and dark themes.

Home groups saved work beside one actionable next step. Its launcher recognizes
one skill name in English or Vietnamese and opens that existing library; it is
not an AI prompt or a topic-search service. Ambiguous input asks for one skill.
The four shortcuts remain available without typing.

Keep existing attempt, recording, consent, draft, source-license, scoring and
backup behavior. Do not add invented bands, streaks, vocabulary, paid features
or an AI tutor merely because they appear in the reference. Speaking's circular
microphone is the existing opt-in recording action, not an automatic recorder.

## Verification

Check launcher routing, theme persistence, saved-work resumption, accessible
navigation and desktop/mobile overflow alongside the existing practice tests.
Inspect screenshots of Home and active practice, not only library pages.
