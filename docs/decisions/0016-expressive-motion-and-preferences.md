# 0016 — Expressive motion and separate preferences

User explicitly replaces the quiet-motion policy with visible interaction motion.
Keep Manrope, violet #6146ee, light #f8f9fd, dark #171720, ink #19192f,
cyan #63dbe9 and borders #e7e6f1. Home's launcher is the expressive focal point:
a travelling perimeter beam and two-second sliding suggestions. Skill icons
use subject-specific SVG animation. A measured sidebar pill moves between real
destinations; navigation uses an outgoing/incoming blur, slide and stretch.
Reduce-motion and a personal motion-off choice override everything.

Settings becomes /settings for local configuration, permissions, audio devices,
backup and data disclosures. Avatar opens personal preferences: name, a preset
avatar, light/dark/system/ambient, Pomodoro and configurable transition style,
speed and hover motion. Ambient means a static tinted visual theme, not audio.
Preferences stay on this browser in a separate versioned UI key, not learner
backup or scoring schema. Name/avatar are local personalization, not an account.
Microphone access remains explicit and tracks are stopped after device discovery.
No AI calls, new dependencies, remote assets or automatic audio playback.
SVG MaKeng mark combines an open book, M and ascending learning path.
